# hwo-hri-uk

Public website of the UK-led team developing the High Resolution Imager (HRI) for NASA's Habitable Worlds Observatory (HWO).

The site is a single self-contained page, `index.html`, served with GitHub Pages.

## Editing

- Edit `index.html` directly (on GitHub: open the file, click the pencil icon, then "Commit changes"). The live site updates within a minute or two.
- Update the "Last reviewed" date in the footer whenever content changes.
- Logo files (dark and white versions, and a square icon) are in the `logo` folder.
- The full team list is marked as a trial in the HTML (between `TRIAL` and `END TRIAL` comments) and can be deleted as one block.
- The "Join the mailing list" button links to a Microsoft Form ("HWO HRI UK: news and updates") owned by Vincent Van Eylen's UCL account; responses are collected there.
- The HWO2026 (Paris) entry under Meetings needs updating after December 2026.

## Custom domain

Once a domain such as `hwo-hri-uk.org` is registered, add it under Settings → Pages → Custom domain, and set the DNS records GitHub shows there.
